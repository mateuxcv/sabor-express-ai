# Arte da capa

`restaurant-editorial.webp` é a versão otimizada da arte criada com Azure GPT Image para esta capa.

Original: `generated-media/image-b400c841-0545-4cfb-8770-28b4009803cb-1.png`.

A imagem é usada no carregamento e na experiência ilustrada de contingência. A maquete interativa é construída em Three.js com geometrias e materiais locais; não depende de modelos, fontes 3D ou serviços externos.
